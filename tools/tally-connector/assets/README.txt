Drop the following files here before running `npm run dist`:

  icon.ico            — 256x256 Windows installer + window icon
  iconTemplate.png    — 16x16 or 32x32 tray icon (macOS: use monochrome
                        template; Windows: use full-colour PNG)

If missing, electron-builder will fail with "cannot find icon.ico".
Any 256x256 .ico works for the pilot — polish the branded icon later.
