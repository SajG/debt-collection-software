# Mobile app assets

Placeholders live here — solid SynWorks-green PNGs generated by
`scripts/generate-placeholder-assets.mjs`. They're real, valid PNGs so
`eas build` succeeds today; swap them for final art whenever design
ships it.

Required sizes:

| File                | Size (px)     | Purpose                          |
| ------------------- | ------------- | -------------------------------- |
| `icon.png`          | 1024 × 1024   | App icon (iOS + Android generic) |
| `adaptive-icon.png` | 1024 × 1024   | Android adaptive-icon foreground |
| `splash.png`        | 1284 × 2778   | Splash screen (portrait iPhone)  |
| `favicon.png`       | 48 × 48       | Expo Web favicon (dev tool only) |

Regenerate placeholders (idempotent):

```
npm run assets:placeholder
```
